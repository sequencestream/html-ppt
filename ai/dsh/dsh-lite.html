0415
核心难题
SAFE RECOMPOSITION

难的不是加载插件，而是安全地换件

01 / Teardown
副作用能撤销吗
监听器、定时器、句柄要全回收。
02 / Dependency
依赖变了怎么办
下游要自动停用、重载、恢复。
03 / Continuity
能不重启进程吗
会话与本地状态要保持连续。
时间可组合性
Revertible Effects
组件移除后，改动能完整撤销。
空间可组合性
Reactive Coeffects
依赖出现、消失、替换都被响应。
动态重组 = 副作用回收 + 依赖协调 + 状态一致。

Cordis 原理一
REVERTIBLE EFFECTS

副作用必须自带逆操作

ctx.effect(() => { const t = setInterval(fn, 1000) return () => clearInterval(t) })
创建与撤销写在一起

但这不等于回滚正确

0615
Cordis 原理二
REACTIVE COEFFECTS

依赖变化，直接驱动组件生命周期

依赖齐备

自动激活，不用人工排启动顺序。

provider 消失

消费方停用，不再调用失效服务。

provider 替换

消费方重载，重新绑定新实现。

provider 卸载

先停服务，等下游收尾，再回收自身。

普通 DI 启动时解析一次；这里的依赖解析是持续的运行时过程。
